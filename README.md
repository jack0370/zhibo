# 私域直播互动直播间 · MVP 第一版

录播视频 + 预设互动 + 真实评论，营造接近真实直播间的参与感。
第一版只做三件事：①直播间画面 ②互动区 ③评论区。**不做**咨询/报名/商品卡片/支付/注册登录。

## 运行

```bash
npm install
npm start
```

- 前台直播间：http://localhost:3000
- 后台管理：http://localhost:3000/admin.html （默认密码 `admin123`）

> 想换端口：`PORT=8080 npm start`
> 数据存在 `data/db.json`（已 gitignore）。删掉它重启 = 恢复出厂示例数据。

## 上手 3 步

1. 进后台 → **直播间配置**：把「视频嵌入代码」换成你的 Voomly `<iframe>`，填好标题、观看人数。
2. **预设互动**：编辑/新增/批量导入互动评论（「时间」= 开播后第几秒弹出）。
3. 点 **🔴 立即开播** → 打开前台，预设互动会随播放进度自动滚出，观众可在底部发言。

## 核心机制：全局直播时钟

- 后台「立即开播」会记录开播时间戳；所有观众共享同一条时间线。
- 前台用「服务器时间」校正本地时钟，按 `已播秒数` 揭示预设互动。
- 晚进来的观众会看到最近 ~15 条作为历史回填，之后实时滚出（像真直播迟到）。
- 真实评论每 ~3 秒轮询一次，混入互动流。

## 功能清单

**前台**：移动端优先；顶栏（名称/课程/状态/人数）；嵌入视频；评论流叠加；预设按进度出现；底部输入；首评填昵称（地区可选，存 localStorage）；无注册、不采集手机号/WhatsApp/LINE；服务端敏感词过滤 + 限频。

**后台**：直播间配置（标题/视频代码/封面/状态/人数/开播）；预设互动管理（增删改、启用停用、JSON 批量导入导出）；用户评论管理（查看/隐藏/通过/删除/一键加入预设库）。

## 目录

```
public/admin.html  后台（admin.css / admin.js）
data/db.json       运行时数据（gitignore）
```

## 已知边界（MVP 取舍）

- 数据存 JSON 文件，适合单机/小流量验证；上量再换 SQLite/Postgres。
- 视频用 iframe 嵌入，跨域无法读真实播放进度，故用「全局直播时钟」对齐，不做视频 seek。
- 实时用轮询（3s），不上 WebSocket。
- 后台单一共享密码，够 MVP 用；对外上线建议加 HTTPS 与更强鉴权。
- 默认密码 `admin123` 与敏感词在 `lib/seed.js`，正式用前请修改。
